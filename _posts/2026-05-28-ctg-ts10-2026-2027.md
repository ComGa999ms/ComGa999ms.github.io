## Bài 1: Đóng gói kiện hàng (5 điểm)

**Đề bài:** Tìm số cách chia $N$ kiện hàng vào các thùng sao cho số kiện ở mỗi thùng bằng nhau và không dư.

Thực chất, đây là bài toán đếm số lượng ước nguyên dương của $N$.

### Subtask 1: $N \le 10^6$
- Ta có thể duyệt từng số $i$ từ $1$ đến $N$.
- Nếu $N$ chia hết cho $i$, nghĩa là $i$ là một cách chia hợp lệ.
- Mỗi lần tìm được một ước, tăng biến đếm lên $1$.
- Cách này đủ nhanh với giới hạn $N \le 10^6$.
- **Độ phức tạp:** $O(N)$.

### Subtask 2: $N \le 10^9$
- Với $N$ lớn hơn, duyệt tới $N$ sẽ quá chậm.
- Nếu $i$ là ước của $N$, thì $\frac{N}{i}$ cũng là ước của $N$.
- Do đó, ta chỉ cần duyệt $i$ từ $1$ đến $\sqrt{N}$.
- Nếu $N$ chia hết cho $i$:
  - Nếu $i \ne \frac{N}{i}$, cộng thêm $2$ ước.
  - Nếu $i = \frac{N}{i}$, tức $N$ là số chính phương, chỉ cộng thêm $1$ ước.
- **Độ phức tạp:** $O(\sqrt{N})$.

### Code mẫu

```cpp
#include <bits/stdc++.h>
#define int long long
#define endl '\n'

using namespace std;

void solve(void) {
    int n;
    cin >> n;

    int ans = 0;
    for (int i = 1; i * i <= n; ++i) {
        if (n % i == 0) {
            if (i * i == n) ++ans;
            else ans += 2;
        }
    }

    cout << ans;
}

signed main() {
    ios_base::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    solve();
    return 0;
}
```

## Bài 2: Chiếc giày thất lạc (5 điểm)

**Đề bài:** Cho mảng gồm $N$ phần tử. Tất cả các giá trị đều xuất hiện theo cặp, ngoại trừ một phần tử duy nhất bị khuyết một chiếc. Cần tìm phần tử đó.

### Subtask 1: $N \le 10^5, a_i \le 10^6$
- Vì giá trị $a_i$ không quá lớn, ta có thể dùng mảng tần số.
- Khởi tạo mảng đếm $C$ toàn giá trị $0$.
- Với mỗi giá trị $a_i$, tăng $C[a_i]$ lên $1$.
- Sau khi đọc xong, duyệt mảng $C$ để tìm giá trị có tần số lẻ.
- Giá trị đó chính là chiếc giày bị thất lạc.
- **Độ phức tạp:** $O(N + \max(a_i))$.

### Subtask 2: $N \le 10^5, a_i \le 10^9$
- Khi $a_i$ có thể rất lớn, không thể dùng mảng tần số.
- Ta dùng phép XOR.
- Tính chất quan trọng:
  - $x \oplus x = 0$.
  - $x \oplus 0 = x$.
- Vì các phần tử xuất hiện theo cặp sẽ tự triệt tiêu khi XOR, phần tử còn lại chính là đáp án.
- Khởi tạo $ans = 0$, sau đó với mỗi $a_i$ thực hiện ans ^= $a_i$.
- **Độ phức tạp:** $O(N)$.

### Code mẫu

```cpp
#include <bits/stdc++.h>
#define int long long
#define rep(i, l, r) for (int i = l; i <= r; ++i)
#define endl '\n'

using namespace std;

void solve(void) {
    int n;
    cin >> n;

    int ans = 0;
    rep(i, 1, n) {
        int x;
        cin >> x;
        ans ^= x;
    }

    cout << ans;
}

signed main() {
    ios_base::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    solve();
    return 0;
}
```

## Bài 3: Tin nhắn bí mật (5 điểm)

**Đề bài:** Phục hồi tin nhắn gốc từ một chuỗi bị lặp kí tự khi nhấn giữ. Dấu `*` được dùng để ngăn cách trong trường hợp hai kí tự giống nhau đứng liền kề trong xâu gốc.

### Subtask 1: Xâu $S$ không có dấu `*`
- Khi không có dấu `*`, mỗi đoạn gồm các kí tự giống nhau liên tiếp chỉ đại diện cho một kí tự trong tin nhắn gốc.
- Ta duyệt xâu $S$ từ trái sang phải.
- Nếu kết quả đang rỗng hoặc kí tự hiện tại khác kí tự cuối cùng trong kết quả, ta thêm kí tự đó vào kết quả.
- Nếu kí tự hiện tại giống kí tự cuối trong kết quả, bỏ qua vì đó là lỗi nhấn giữ.
- **Độ phức tạp:** $O(\lvert S \rvert)$.

### Subtask 2: Xâu $S$ có cả chữ cái và dấu `*`
- Dấu `*` cho biết nhóm kí tự lặp tiếp theo là một kí tự mới, kể cả khi nó giống kí tự ngay trước đó.
- Dấu `*` ở đầu hoặc cuối xâu không tạo thêm chữ cái nào, nên có thể bỏ qua.
- Dùng biến `seen_star` để đánh dấu việc ta vừa đi qua ít nhất một dấu `*` kể từ chữ cái cuối cùng.
- Khi duyệt từng kí tự:
  - Nếu gặp `*`, đặt `seen_star = true`.
  - Nếu gặp chữ cái, ta thêm vào kết quả khi:
    - Kết quả đang rỗng.
    - Kí tự hiện tại khác kí tự cuối của kết quả.
    - Kí tự hiện tại giống kí tự cuối của kết quả nhưng `seen_star = true`.
- Sau khi xử lý một chữ cái, đặt lại `seen_star = false`.
- **Độ phức tạp:** $O(\lvert S \rvert)$.

### Code mẫu

```cpp
#include <bits/stdc++.h>
#define endl '\n'

using namespace std;

void solve(void) {
    string s;
    cin >> s;

    string ans;
    bool seen_star = false;

    for (char c : s) {
        if (c == '*') {
            seen_star = true;
            continue;
        }

        if (ans.empty() || c != ans.back() || seen_star) ans += c;
        seen_star = false;
    }
    cout << ans;
}

signed main() {
    ios_base::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    solve();
    return 0;
}
```

## Bài 4: Cập nhật dãy (5 điểm)

**Đề bài:** Cho mảng $A$ ban đầu gồm $N$ phần tử đều bằng $0$. Cần thực hiện $Q$ truy vấn. Mỗi truy vấn $(l, r)$ sẽ cộng cấp số cộng $1, 2, 3, \ldots, r-l+1$ vào đoạn $[l, r]$. Sau tất cả truy vấn, tìm giá trị lớn nhất của mảng.

### Subtask 1: $N, Q \le 10^3$
- Khởi tạo mảng $A$ gồm toàn số $0$.
- Với mỗi truy vấn $(l, r)$, duyệt từng vị trí $i$ từ $l$ đến $r$.
- Giá trị cần cộng vào $A_i$ là $i-l+1$.
- Sau khi xử lý toàn bộ truy vấn, duyệt mảng $A$ để tìm giá trị lớn nhất.
- **Độ phức tạp:** $O(NQ)$.

### Subtask 2: $N, Q \le 2 \times 10^5$
- Không thể cập nhật trực tiếp từng phần tử vì $O(NQ)$ sẽ quá chậm.
- Ta dùng mảng hiệu bậc hai.
- Gọi $D_i = A_i - A_{i-1}$ là mảng hiệu bậc một.
- Gọi $D2_i = D_i - D_{i-1}$ là mảng hiệu bậc hai.
- Khi cộng cấp số cộng $1, 2, 3, \ldots, K$ vào đoạn $[l, r]$, với $K = r - l + 1$, ta chỉ cần cập nhật:
  - $D2_l$ tăng $1$.
  - $D2_{r+1}$ giảm $K + 1$.
  - $D2_{r+2}$ tăng $K$.
- Sau khi xử lý toàn bộ truy vấn:
  - Khôi phục $D$ bằng cách cộng dồn $D2$.
  - Khôi phục $A$ bằng cách cộng dồn $D$.
  - Trong lúc khôi phục $A$, cập nhật đáp án lớn nhất.
- **Độ phức tạp:** $O(N + Q)$.

### Code mẫu

```cpp
#include <bits/stdc++.h>
#define int long long
#define rep(i, l, r) for (int i = l; i <= r; ++i)
#define endl '\n'

using namespace std;

const int N = 2e5 + 5;

int n, q;
int d2[N];

void solve(void) {
    cin >> n >> q;

    while (q--) {
        int l, r;
        cin >> l >> r;

        int k = r - l + 1;
        d2[l] += 1;
        d2[r + 1] -= k + 1;
        d2[r + 2] += k;
    }

    int diff = 0, cur = 0, ans = 0;
    rep(i, 1, n) {
        diff += d2[i];
        cur += diff;
        ans = max(ans, cur);
    }

    cout << ans;
}

signed main() {
    ios_base::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    solve();
    return 0;
}
```
